ABOUT THE PROJECT

Understanding students through data.

StudentAI is a student performance prediction and analytics project designed to demonstrate how academic and lifestyle information can be used to estimate student performance.

01

Project Objective

Analyze student information and generate an estimated performance score.

02

Input Factors

Study hours, attendance, previous marks, assignments, sleep and screen time.

03

Technology

HTML, CSS and JavaScript are used to create the application.

04

Important Note

Predictions are estimates for educational demonstration purposes.
